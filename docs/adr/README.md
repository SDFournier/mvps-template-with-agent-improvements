# ADRs

ADRs capture the context and rationale behind architectural decisions.
One decision per ADR.

## Relationship to the decision log
- ADRs are the detailed source of truth for each decision.
- The decision log summarizes key decisions and links to ADRs.

## How to add an ADR
1) Copy the template and assign the next number.
2) Keep it short and focused on one decision.
3) Update the decision log with a short summary and link.

## Naming
Use incremental numbers: 0001-title.md.
Use the template at docs/adr/000-adr-template.md.
