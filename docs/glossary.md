# Glossary

- ADR: Architectural Decision Record. One decision per document.
- Decision log: Summary of key decisions and an index to ADRs.
- Contract: A shared agreement about request/response shapes and errors.
- DTO: Data Transfer Object, shared between web and API.
- Playbook: A step by step recipe for a feature.
- Flow: End to end user journey, documented with a diagram.
- Session: Server side auth token stored on the backend.
- Cache TTL: Time to live for cached data.
- Guard: API authorization or validation layer.
- Smoke test: A fast test that validates wiring and dependencies.
- Lab: A small, executable experiment for a concept.
